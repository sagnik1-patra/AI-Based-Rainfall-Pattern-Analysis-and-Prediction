# 🌧️ AI-Based Rainfall Pattern Analysis and Prediction

## 📌 Project Overview

The **AI-Based Rainfall Pattern Analysis and Prediction** project analyzes rainfall information and demonstrates an AI-based rainfall prediction pipeline using **Artificial Neural Networks (ANN)** together with optimization techniques such as **Artificial Immune System (AIS)** and **Particle Swarm Optimization (PSO)**.

The dataset contains **Normal Rainfall** and **Actual Rainfall** measurements. The project analyzes the deviation between these values and uses the observed relationship to construct a demonstration prediction pipeline.

The main AIS implementation applies a **Clonal Selection inspired Artificial Immune System** to optimize important ANN hyperparameters such as the number of hidden neurons, learning rate, and batch size.

The project generates trained models, preprocessing objects, configuration files, metadata, prediction results, evaluation metrics, CSV reports, and multiple visualizations.

---

## 🎯 Objectives

The major objectives of this project are:

- Analyze normal and actual rainfall values.
- Calculate rainfall deviation and percentage variation.
- Identify whether rainfall is above normal, below normal, or normal.
- Build an Artificial Neural Network for rainfall prediction.
- Apply **Artificial Immune System (AIS)** optimization.
- Apply **Particle Swarm Optimization (PSO)** for comparison.
- Optimize ANN hyperparameters automatically.
- Generate rainfall predictions for different rainfall conditions.
- Evaluate model performance using regression metrics.
- Generate graphical representations of prediction results.
- Save trained models and preprocessing components for future use.
